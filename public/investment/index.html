Teil 3 · Spielregeln

Die KI analysiert. Ihr entscheidet.

1

Keine Order ohne Freigabe

Gehandelt wird im wikifolio – mit virtuellem Geld und erst nach Freigabe durch das Komitee.

2

Keine Anlageberatung

Scores und faire Werte beschreiben die Vergangenheit, nicht die Zukunft. KI-Antworten können Fehler enthalten.

3

Nachprüfen

Jede Zahl, die in eine Entscheidung geht, einmal direkt im Aktienfinder gegenchecken.

4

Eure These zuerst

Ein Satz, warum ihr kaufen wollt – bevor ihr die KI fragt. Dann darf sie widersprechen.

Unser Prinzip: Erst denken, dann KI. Wer die Entscheidung abgibt, lernt nichts – und trägt das Risiko trotzdem.

Der AG-Fonds · Umsetzung

Rollen, Stufen, Setup.

Rollen
  • Research: screenen, Memos prüfen
  • Risiko: wacht über das Statut
  • Trading-Desk: setzt die Orders im wikifolio
  • Reporting: Wochenbericht, später Dashboard
  • Komitee: alle, entscheidet
In drei Stufen
  • Start: Claude bereitet Orders vor, ihr setzt sie im wikifolio
  • Öffentlich: wikifolio veröffentlichen, jeder Trade mit Kommentar
  • Option voll verbunden: Agent auf Alpaca oder wikifolio-API auf Anfrage
Euer eigenes Setup
  • Aktienfinder, Claude, wikifolio ✓ habt ihr
  • Aktienfinder-Connector in Claude verbinden: 2 Minuten
  • Eigenes Test-wikifolio für eure Ideen
  • Optional: eigenes Alpaca-Spielgeld-Konto, Server lokal auf eurem Laptop

Grenzen: wikifolio hat keinen KI-Connector, Orders werden von Hand gesetzt · Echtes Geld (Status „investierbar“) erst ab 18 – bleibt bei uns aus
